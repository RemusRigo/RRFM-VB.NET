# RRFM Update My File

A Windows tool that copies/updates the content of a file to a group of selected files



## Authors

* [@remusrigo](https://github.com/RemusRigo)
* [@remusrigo](https://sourceforge.net/u/remusrigo/profile)



## Installation

* You must install .NET Runtime 10 x64 and then just run RRFM UpdateMyFile.exe
* Tested on:

  * Windows 11 Pro x64
